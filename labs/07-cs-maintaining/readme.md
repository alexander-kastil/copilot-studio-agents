# Publishing & Maintaining Copilot Studio Agents

This lab maintains an agent from the terminal: Claude Code with the Copilot Studio plugins clones the Grey Logistics IT Help Desk agent, reviews it, adds a validated topic, publishes and tests it, then migrates it to the Microsoft Copilot harness. The theory and demos for each topic are in [demos/07-cs-maintaining](../../demos/07-cs-maintaining/readme.md).
