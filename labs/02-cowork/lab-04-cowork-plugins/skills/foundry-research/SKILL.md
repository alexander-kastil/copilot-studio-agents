# Foundry Research

Compile a sourced summary of Microsoft Foundry for the user's question.

## Workflow

1. Restate the research question in one sentence and list the sub-topics it touches: documentation, architecture, models, deployment options and features.
2. Search Microsoft Learn for each sub-topic. Use the Microsoft Learn search tool if the session provides one. If it does not, say so and ask the user for the Microsoft Learn pages to use.
3. Open the most relevant pages and read them. Do not summarize from search snippets alone.
4. Write the summary with one heading per sub-topic, a short paragraph under each, and a Links section that lists every page used with its URL.
5. Mark anything the pages do not cover as not found. Do not fill the gap from memory.
