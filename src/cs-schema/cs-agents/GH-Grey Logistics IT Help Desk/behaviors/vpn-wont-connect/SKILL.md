# VPN won't connect

## When to use
The user reports that the VPN does not connect, fails to connect or cannot be reached. No tool is needed and the user is not redirected elsewhere.

## Steps
1. Ask which operating system the user uses: Windows or macOS. If the answer is already in the conversation, do not ask again.
2. Give the four steps for that system, as a numbered list, in the user's language.

### Windows
1. Check that your internet connection works by opening any website.
2. Disconnect from the VPN, restart the VPN client and connect again.
3. Open Settings, then Network and Internet, then VPN, remove the VPN profile and add it again.
4. Restart your computer and try once more.

### macOS
1. Check that your internet connection works by opening any website.
2. Quit the VPN client completely, reopen it and connect again.
3. Open System Settings, then VPN, remove the VPN configuration and add it again.
4. Restart your Mac and try once more.

## Fallback
If the user says the steps did not help, say so honestly and point them to the IT help desk. Do not invent further fixes.
