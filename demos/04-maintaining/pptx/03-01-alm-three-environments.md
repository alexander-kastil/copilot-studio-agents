# ALM for Copilot Studio agents

## Content

- **Three environments**: development, test and production
- Customize **only in development**
- Always work **in the context of solutions**
- Decide **managed or unmanaged** when you import
- Pipelines and source control make each release **automated and auditable**

## Speaker Notes

Application Lifecycle Management is the discipline of moving an agent through development, test and production in a way that is reliable and repeatable. This slide gives the model and its golden rules.

Three environments: makers build in development, changes are validated in test, and agents reach real users in production.

Only in development: the first golden rule is never to customize outside development.

In the context of solutions: the second golden rule. Solutions are the carrier that transports the agent between the environments.

Managed or unmanaged: when you import a solution into the next environment, you decide whether it arrives managed or unmanaged.

Automated and auditable: without ALM, promoting an agent means rebuilding it by hand and hoping nothing drifts. Pipelines and source control turn that manual ritual into an automated, auditable release.
