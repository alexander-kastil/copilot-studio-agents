# Custom solutions

## Content

- New agents land in the **default solution** automatically, fine for a quick build
- Create a **custom solution** for anything you plan to promote
- Set it as your **preferred solution** so new components are captured as you build
- Give it a **custom publisher and prefix**

## Speaker Notes

The previous slide showed where an agent lives. This one is about the solution it lands in, and why that choice is made before the first component exists.

Default solution: agents created in Copilot Studio land there automatically. That is fine for a quick build, but not for anything you plan to promote.

Custom solution: to export, import and manage agents across environments, you create a custom solution of your own.

Preferred solution: set the custom solution as your preferred solution, so every new component is captured in it as you build. Getting this right early is what makes clean deployments possible later.

Custom publisher and prefix: create the custom solution with a publisher and prefix of your own. Managed versus unmanaged is the other solution choice; it comes back when you import in the ALM topic.
