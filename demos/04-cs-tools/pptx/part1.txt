# Calculating the canteen order with a prompt
### CS-Food Stock Buddy passes demand and stock as JSON
- The topic binds both inputs with **JSON()** and reads the answer from the output's `text` field
- kind: InvokeAIBuilderModelAction

```
- kind: InvokeAIBuilderModelAction
  input:
    binding:
      foodDemand: =JSON(Global.orderDemand)
      foodStock: =JSON(Topic.foodStock)
  output:
    binding:
      predictionOutput: Topic.orderQuantityRecord
```

# Writing and testing a prompt
### Instructions, typed inputs and a test before anyone uses it
- The **instructions** say what the model does and what the answer looks like
- Typing **/** inserts an input; foodDemand and foodStock are Text inputs
- **Test** with sample values first, and save only when the output has the right shape
- "Return only a JSON array" and **temperature 0** keep the output easy to parse
