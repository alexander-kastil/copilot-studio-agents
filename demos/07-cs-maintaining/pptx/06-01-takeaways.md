# Takeaways

## Content

- Build in a **custom solution**, set as preferred, from the first component
- **Publish** once to every channel and choose the **authentication model** with care
- Promote with **pipelines and Git**, then finish the **post-deployment steps**
- Let a **coding agent** author, validate and push the agent as files

## Speaker Notes

Close the module with the habits that take an agent from a personal sandbox to a production environment.

Custom solution: create it and set it as your preferred solution before you build, so every component is captured and the agent can move between environments.

Publish and authenticate: one publish updates every connected channel, and the authentication model decides who can chat with the agent and which channels and tools still work.

Pipelines and Git: promote the solution through development, test and production, then set up channels, authentication, sharing and Application Insights in the target.

Coding agent: with the copilot-studio and mcs-assistant plugins every change becomes a file you can diff and review, and the portal stays the place to publish.
