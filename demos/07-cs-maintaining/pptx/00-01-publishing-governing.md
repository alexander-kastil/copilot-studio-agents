# Publishing & Maintaining Copilot Studio Agents

## Content

- **Publish** to the channels where people already work
- **Promote** from development to test to production with solutions
- **Build and migrate** agents from the terminal with coding agents

## Speaker Notes

Building an agent is only half the job. This module covers what comes after it works on your screen: taking it from a personal sandbox to a production environment.

Publish: one publish puts the agent into Teams, Microsoft 365 Copilot and SharePoint, and the optional topic adds websites, Direct Line and WhatsApp.

Promote: solutions, deployment pipelines and Git move the agent between development, test and production without rebuilding it by hand.

Build and migrate: the last topic hands the authoring to Claude Code with two Copilot Studio plugins, using the Grey Logistics IT Help Desk agent from module 3.
