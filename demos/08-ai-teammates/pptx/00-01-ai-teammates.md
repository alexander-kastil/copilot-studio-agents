# AI Teammates: Autopilot & Agent Accounts

## Content

- **Autopilot**: the persistent personal agent a user sets up in Copilot
- **Agent accounts**: a Copilot Studio agent with its own Entra ID, mailbox and Teams presence
- **Frontier previews** you run in a prepared tenant

## Speaker Notes

Cowork completes the work you hand it, and a Copilot Studio agent answers when someone asks. A teammate agent holds its own identity, remembers what the team tells it and keeps a business process moving without waiting for a prompt.

Autopilot: the persistent personal agent Microsoft announced on September 25, 2026. A user gives it a name, a role and a goal, and in Microsoft's supplier review example it prepares the reviews and follows up with stakeholders.

Agent accounts: the build path for makers. A Copilot Studio agent gets its own Microsoft Entra ID, mailbox and Teams presence, so colleagues work with it like with any member of the organization.

Frontier previews: both are Frontier previews as of October 2026. Agent accounts need a Frontier-enrolled tenant, an early release environment and per-agent licenses, so the admin steps come before the class.
