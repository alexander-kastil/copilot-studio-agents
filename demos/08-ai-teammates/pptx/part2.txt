# Identity and preview limits
### Decisions to settle before you publish
- The **email address** starts with your alias, and the agent reports to you
- In the preview neither can change, and the **address** stays fixed once you publish
- **No external users** and **no co-authoring**: it writes new documents and leaves existing ones as they are
- It replies only in conversations with up to **250 people**
- It cannot read files labeled **Confidential** or **Internal Only**

# Tool authentication
### From the author's credentials to the agent's own
- **Without an account**: an event trigger runs on the author's credentials, and Publish warns about it
- **With an account**: the agent acts as itself, with its own scoped access rights
- **Agent account** becomes the default authentication for every tool that supports it
- **End-user authentication** still needs each person's consent through Go to Agent Management
- Check which identity each tool uses and grant only the **access the job needs**

# Triggers, tools and instructions
### Three pieces that start an agent's cycle
- **Recurrence**: the schedule you set comes around
- **Email**: a message arrives in the agent's mailbox
- **A person**: someone @mentions it or sends it a task
- Instructions alone don't create a **schedule** or grant access
- Triggers for the **GitHub Copilot harness** were announced on October 15, 2026

# The Cadence pattern
### An execution-review agent from the Learn documentation
- **Inputs**: an approved workstream tracker and a small internal reviewer group
- Each **scheduled run** reads the tracker, finds blockers and creates a review document
- A **new document** each cycle, because co-authoring is not supported
- **Preserve uncertainty**: a missing reply does not mean the work is on track
- **Stop and explain** when a source, connection or permission is missing

# Shared memory
### One memory for everyone the agent works with
- **One memory** across everyone it works with, even in one-to-one chats
- **No privacy boundary**: a record about one person can come up with others
- **Never kept**: personal details, secrets, judgments, sensitive categories and requests to forget
- Anyone who interacts can **view or delete** saved memories; 28 days without interaction deletes them
- **No opt-out** in the preview: share only what the whole team may know

# Admin activation
### Four steps, in order, before anyone builds
- **Frontier enrollment** by a global admin, accepting the Agent 365 terms
- **Copilot Studio (Frontier)** activated for the users or groups allowed to build
- **Agent accounts** turned on for the environment in the Power Platform admin center
- The environment's **release cycle** set to Early
- In the **European Economic Area**, Teams presence needs a Teams license

### Three separate things to plan
- **Maker license**: Microsoft 365 E5 with the Agent 365 add-on, or Microsoft 365 E7
- **Frontier for AI Teammates**: one per agent with an account, from the tenant's pool
- **Copilot Credits**: building, testing, evaluating and running the agent
- **Agent 365** has been generally available per user since May 1, 2026

# Takeaways
### What to settle before a teammate joins the team
- A **teammate** acts as itself, remembers for the team and starts without a prompt
- **Autopilot** for users who describe a goal, agent accounts for makers who need tools and triggers
- **Trigger, tools and instructions** must all be configured before an agent acts
- **Shared memory** reaches everyone the agent works with
- **Frontier enrollment and licenses** come before the class
