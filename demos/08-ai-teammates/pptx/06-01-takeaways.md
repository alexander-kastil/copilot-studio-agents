# Takeaways

## Content

- A **teammate** acts as itself, remembers for the team and starts without a prompt
- **Autopilot** for users who describe a goal, agent accounts for makers who need tools and triggers
- **Trigger, tools and instructions** must all be configured before an agent acts
- **Shared memory** reaches everyone the agent works with
- **Frontier enrollment and licenses** come before the class

## Speaker Notes

Five points to carry out of this module. Both products are Frontier previews as of October 2026, so treat the module as a forward look you run in a prepared tenant, with the readiness checklist done first.

Teammate: identity, memory, reach and persistence separate it from an assistant. It owns a process instead of finishing one task.

Autopilot or agent account: a user sets up Autopilot with a name, a role and a goal. A maker builds an agent with an account when the process needs its own instructions, tools and triggers.

Trigger, tools and instructions: instructions alone do not create a schedule or grant access. The Cadence pattern shows all three working together.

Shared memory: there is no privacy boundary between users and no opt-out in the preview. Tell people to share only what they would share with the whole team.

Frontier enrollment and licenses: activation runs in four steps, and each agent with an account takes a Frontier for AI Teammates license from the pool. Check the pool before participants publish.
