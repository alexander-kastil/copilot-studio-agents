# Autopilot in the new Copilot

## Content

- **Home**: the new starting point where Chat and Cowork come together
- **Code**: an app, tracker, dashboard or automation built from a description
- **Autopilot**: a persistent, proactive and personal agent that keeps working when you're not
- Its own **identity, memory, computer and workspace**, built on Microsoft IQ
- Previously **Microsoft Scout**; unrelated to Windows Autopilot in Intune

## Speaker Notes

On September 25, 2026, Microsoft introduced a redesigned Copilot with three parts. This slide places Autopilot among them.

Home: Chat and Cowork come together here. Copilot routes each request to Chat, Cowork or Code.

Code: anyone describes an app, tracker, dashboard or automation in natural language. It is powered by the same technology as GitHub Copilot and runs in a sandbox that can be hosted in your tenant.

Autopilot: Microsoft calls it your digital teammate. You give it a name, a role and a goal, and in the supplier review example it builds the schedule and workback plan, handles prep and follow-ups, and reaches out to stakeholders for updates.

Identity, memory, computer and workspace: Autopilot is cloud-hosted in your tenant and grounded in Microsoft IQ. Permissions, audit and governance sit behind every action.

Microsoft Scout: Learn still documents the product under that name as of October 2026. Windows Autopilot is Intune device provisioning, and the GitHub Copilot app has its own Autopilot session mode.
