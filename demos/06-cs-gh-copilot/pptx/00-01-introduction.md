# GitHub Copilot agents next to Standard agents

## Content

- **Two kinds of agent** in one tenant: Standard and GitHub Copilot, chosen when you create the agent
- **The Build tab**: skills, tools, MCP servers, workflows and IQ grounding in one place
- **Beside the agent**: apps built from a description, and test sets that show whether the agent is any good

## Speaker Notes

In June 2026 Microsoft shipped a rebuilt Copilot Studio, so one tenant now holds two kinds of agent. This module teaches GitHub Copilot agents next to the Standard agents from Basics, Tools and Advanced.

Two kinds of agent: you pick Standard or GitHub Copilot in the New agent menu, and an agent can't be converted later. Standard agents stay the primary production track, and GitHub Copilot agents run as guided demos and labs.

The Build tab: a GitHub Copilot agent keeps instructions, knowledge, tools and skills in one panel, with an orchestration runtime that plans across steps. Skills, MCP servers, workflows and Work IQ, Foundry IQ and Fabric IQ all attach there.

Beside the agent: Copilot Studio also builds apps from a plain-language description, and test sets on the Evaluate tab show whether an agent is ready to ship. For every idea, the module shows the Standard equivalent so the concept carries over.
