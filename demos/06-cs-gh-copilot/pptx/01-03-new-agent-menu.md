# The New agent menu

## Content

- Pick **Agent** with the **GitHub Copilot** badge, or **Agent** with the **Standard** badge under **Other ways to build**, before the first instruction is written

## Speaker Notes

This slide shows the one place where the kind of agent is decided: the arrow next to New agent on the Agents page. The diagram redraws the menu as the live run in the class tenant showed it.

GitHub Copilot: under Optimize your business processes, Agent with the GitHub Copilot badge creates "an agent to take actions and answer questions". The Home page offers the same agent as a card.

Standard: under Other ways to build, Agent with the Standard badge creates "an agent with predefined rules and flows". Some Learn pages for Standard agents still start with "Turn off New experience"; when the tenant shows this menu, use it, and the result is the same Standard agent.

Before the first instruction: the live run built GH-Health Advisor from this menu for topics one to three. Because there is no conversion, this click is the decision to check twice.
