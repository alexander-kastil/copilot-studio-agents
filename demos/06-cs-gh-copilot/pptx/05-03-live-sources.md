# Live sources and uploaded files

## Content

- An **uploaded file** is an indexed copy: the agent knows what you uploaded last
- An **IQ connection** reads the source where it lives when the question arrives
- That matters for information that moves, such as a **customer email from this morning**
- You change a file by uploading a new version; an IQ source is tuned by its **owner**

## Speaker Notes

This slide steps back from the demo to the reason it matters. An account manager who asks about yesterday's customer email gets a confident answer only when the agent can read that email.

Uploaded file: the agent indexes a copy you supplied, and you change what it knows by uploading a new version. That suits a document set you own, such as the Northwind product reference.

IQ connection: Work IQ, Foundry IQ and Fabric IQ point at a source that already exists elsewhere, so the answer reflects its current state. Copilot Studio holds only the connection.

Information that moves: a customer email from this morning or a figure refreshed overnight is something a file uploaded last week cannot answer.

Owners: administrators govern Work IQ, the owning team tunes a Foundry knowledge base, and the workspace owner decides what a Fabric semantic model holds. Work IQ and Fabric IQ are in preview, and all three use usage-based billing.
