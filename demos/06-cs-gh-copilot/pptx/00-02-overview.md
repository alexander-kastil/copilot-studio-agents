# Overview

## Content

- Start with the **two kinds of agent**: how to choose, tell them apart, and what the new orchestrator does
- On the **Build tab**: Agent Skills, then tools, MCP servers and the new workflows designer
- **Ground** the agent with Work IQ, Foundry IQ and Fabric IQ
- **Build an app** from a description, then **test and evaluate** the agent before it ships

## Speaker Notes

This slide walks the path through the seven topics once, following on from the three themes of the title slide.

Two kinds of agent: topic one covers the New agent menu, coexistence and the one-way conversion rule. Topic two maps the Standard settings onto the four-tab Build surface and explains the always-on orchestration runtime.

Build tab: topic three packages task recipes as skills in the open SKILL.md format. Topic four adds connectors, MCP servers and workflows with agent nodes from one Tools surface.

Grounding: topic five connects Work IQ, Foundry IQ and Fabric IQ, each reading a source that stays where it lives.

Apps and evaluation: topic six turns a description into a working app, and topic seven runs test sets on the Evaluate tab and walks a failing case to its fix.
