# Building & Testing Agents with Microsoft Copilot Studio

## Content

- Build a first agent on the **classic authoring surface**, ground it and publish it
- Extend it with **tools**, then let generative orchestration run it on its own
- Preview the rebuilt **New Experience** that shipped in June 2026

## Speaker Notes

This module is where the class builds agents with Copilot Studio, Microsoft's low-code platform for building, extending and shipping agents. It works through the classic authoring surface first, then previews the New Experience.

Classic authoring surface: you build a first agent, ground it with knowledge, shape its conversations with topics and publish it to a channel. Most tenants still open this surface by default, and production agents and ALM pipelines live there today.

Tools and orchestration: a grounded agent answers questions, a tooled agent acts. Generative orchestration then lets it plan across several steps and run on its own.

New Experience: Microsoft shipped a rebuilt Copilot Studio in June 2026 that runs beside the classic one. The module teaches it beside classic so every concept carries across.
