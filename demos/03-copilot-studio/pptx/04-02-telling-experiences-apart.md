# Telling the experiences apart

## Content

- **Classic**: Topics, Knowledge, Actions and Settings down the left
- **New experience**: Build, Preview, Evaluate and Monitor tabs across the top
- **Topics** in the navigation always means classic
- Read the tabs **before you create** an agent

## Speaker Notes

The previous slide made the choice; this one gives the habit that protects it: knowing which experience is open before building anything. The diagram puts both surfaces side by side.

Classic navigation: classic lists Topics, Knowledge, Actions and Settings down the left. It is the topic-driven surface students use in production today.

New-experience tabs: the new experience shows Build, Preview, Evaluate and Monitor tabs across the top. A new agent opens on the Build tab with Instructions seeded from its description and empty Knowledge, Tools and Skills.

Topics means classic: if Topics appears in the navigation, you are in classic, full stop. In the demo and the lab, that sign means going back to the home page, turning the toggle on and creating the agent again.

Check before you create: confirming the experience before creating an agent is the single habit that prevents the most rework. A minute spent reading the tabs saves an hour of building in the wrong place.
