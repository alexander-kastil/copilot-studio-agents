# Autopilot or an agent account

## Content

- **Autopilot**: a user describes the name, role and goal
- **Agent account**: a maker configures instructions, tools and triggers in Copilot Studio
- Both end in an **identity** that admins govern in Agent 365 and Entra
- **Private preview**: Autopilot has no general availability date yet
- **Usage-based billing**: Cowork, Code and Autopilot consume Copilot Credits

## Speaker Notes

Two products deliver the teammate model today. This slide shows who builds each one and where both end up.

Autopilot: the ready-made teammate a user sets up in Copilot. The user describes a name, a role and a goal.

Agent account: the build path for a maker who needs control over instructions, tools and triggers. It runs in Copilot Studio on the GitHub Copilot harness.

Identity: both end in the same place, an identity that admins govern like any other member of the organization. Agent 365 and Entra carry that governance.

Private preview: Microsoft expanded Autopilot to private preview at the end of September 2026. Home and Code roll out through the Frontier program first.

Usage-based billing: plan consumption through Copilot Credits rather than a per-user seat. Lab 1 asks you to pick one of the two paths for your own process.
