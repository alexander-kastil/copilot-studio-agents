### Delegate multi-step work across Microsoft 365

- **Extend** it with skills, schedules and plugins
- **Approve** before anything is sent or saved

# Overview
### The path through six topics
- **Get started**: what Cowork is, how it differs from Chat, tenant setup and how a task runs
- **Use and author skills**: the built-in catalog, the Workspace panel and your own `SKILL.md`
- Make the work **recurring** with scheduled prompts and event-driven tasks

# Setting up Cowork access
### A spending policy that selects Cowork
- Every pilot user and the setup admin need a **Microsoft 365 Copilot license**
- Turn on **usage-based billing** under Copilot > Cost Management
- A **spending policy** scoped to the pilot group with Cowork selected grants access; one credit is enough
- **Anthropic models** and **Frontier** are optional for access
- The **discovery** setting controls visibility only

# A typical Cowork interaction
### The Q3 review deck from brief to approved send
- **Describe** the outcome: three attached files and one brief for the Q3 review
- **Watch** the numbered plan, then the steps as Cowork builds the deck
- **Steer** the plan: open with the fleece returns, close with the six open roles
- **Approve** the send at a Send draft? card marked Medium risk
- **Review** the deck under Output, with speaker notes saved in the same file

# Where skills come from
### Built-in, custom and plugin skills load the same way
- **Create** a skill with Customize > Add > Create skill with Cowork, or as a `SKILL.md` in OneDrive
- **Upload** a skill file with Customize > Add > Upload, or use one a colleague shares
- **Plugins** come from Discover, from your IT organization, or as your own uploaded package
- Cowork **reads each description** and loads the skill when the work calls for it
- Type **/** in the composer to call a skill by name from the Skills tab
