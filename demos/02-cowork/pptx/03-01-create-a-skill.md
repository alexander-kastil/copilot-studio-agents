# Three ways to create a skill

## Content

- **Guided flow**: Customize > Skills > Add > Create new
- **Ask in chat**: describe the task you repeat
- **Write it yourself**: a `SKILL.md` in its own folder under `Documents/Cowork/skills/`
- Cowork **discovers** your skills at the start of each conversation, up to 50
- **Upload** a `.md`, `.zip` or `.skill` file and share it with specific users

## Speaker Notes

This slide shows how a custom skill comes into being and when Cowork first sees it. A custom skill teaches Cowork your own recurring work in plain language, with no coding.

Guided flow: Customize > Skills > Add > Create new starts a guided conversation, and Cowork saves the result.

Ask in chat: describe the task you repeat and ask Cowork to build a skill for it. The result lands in the same skills folder as the other paths.

Write it yourself: place a SKILL.md inside its own subfolder of Documents/Cowork/skills/ in your OneDrive. Every path ends as a SKILL.md in that folder.

Discovers: Cowork finds your custom skills at the start of each conversation, and you can have up to 50. A skill you just added shows up in the next new task, not the one already open.

Upload: Customize > Skills accepts a single .md up to 1 MB, or a .zip or .skill archive with SKILL.md at its root, up to 10 MB compressed. Share offers Only you or Specific users in your organization, and Re-share sends the latest version after an edit.
