# Three ways to create a skill
### Every path ends in one OneDrive folder
- **Guided flow**: Customize > Add > Create skill with Cowork
- **Ask in chat**: describe the task you repeat
- **Write it yourself**: a `SKILL.md` in its own folder under `Documents/Cowork/Skills/`
- Cowork **discovers** your skills at the start of each conversation, up to 50
- **Upload** a `.md`, `.zip` or `.skill` file and share it with specific users

# Anatomy of a SKILL.md
### A YAML header plus plain-language instructions
- The **name** matches its folder, and the **description** is what Cowork reads to decide when the skill applies
- **Companion files** sit beside `SKILL.md`, up to 20 files and 10 MB, each named in the instructions

```
---
name: product-pitch
description: Turns a market brief, research report, or product document into a wholesale partner pitch deck in Aurora Outdoor house structure, with every claim traced back to a named source. Use whenever I say build a pitch, pitch this to partners, turn this brief into a deck, or name a range or season to pitch.
---

Produce a seven-card partner pitch deck in the house structure defined by pitch-deck-structure.pptx, which sits in this skill folder.
```

# Running and tuning a skill
### From the first run to a skill that triggers on its own
- **Run it by name** in a new task, then check every claim against the source
- Ask which phrasings **miss the skill** and which instruction let weak claims through
- Cowork folds the fixes into `SKILL.md` through an **Edit file?** card at Medium risk
- The **Skill Report** scores the skill out of 100; 70 counts as ready to share
- Done when it **fires without being named** and saves Aurora Trail Capsule AW26.pptx

# Schedules and triggers
### Repeat a prompt on a cadence or when something happens
- A **schedule** repeats a prompt daily, weekly, monthly or at a set time, up to 25 of them
- A **trigger** starts the task when an email, a Teams channel message or a Teams chat message arrives
- The **Automations** page offers Add, templates such as Daily briefing, and the filters Scheduled, Triggers and Paused
- Each automation has an **Enable** switch and a ... menu to edit, run now, pause or delete it
- The **custom skill** decides how the work is done; the schedule or trigger decides when

# Approvals in automated tasks
### The weekly status report runs every Friday; the send waits for you
- **Create recurring task?** sets the name, Weekly, Friday, 3:00 PM, and a new conversation per run
- The **Description** is the prompt every run receives, including where the draft goes
- **Run once now** is ticked by default; clear it so the first run waits for Friday
- Each run leaves the report under Output and a **Hi Elena** email in your Drafts folder
- **Scheduling the run does not approve the send**: nothing leaves until you say so
