# Built-in skills and the side panel

## Content

- **Built-in skills** cover the common office tasks: Word, Excel, PowerPoint, PDF, Email, Scheduling and more
- Cowork **loads the right skills** itself from the task you describe
- The **side panel** shows Progress, the input and output folders, Skills, Schedule and Permissions
- Each **skill chip** that lights up is one step in Cowork's plan
- A stalled step shows you **which skill to steer**

## Speaker Notes

This slide opens the skills topic with what ships in the box and where you watch it work. The diagram shows one request split into two steps, each lighting its own chip.

Built-in skills: Word, Excel, PowerPoint, PDF, Email, Scheduling, Calendar Management, Meetings, Daily Briefing, Enterprise Search, Deep Research, Communications, Adaptive Cards and App (Frontier) ship with Cowork. The image-generation skill uses ChatGPT Images 2.0 and asks about orientation, style and use when a prompt lacks detail.

Loads the right skills: Cowork chooses the skills from the task you describe, so you never invoke one by name. You can narrow the set for a conversation with the Sources picker.

Side panel: it shows a progress bar with a step log, the files you provided, the files Cowork created, the loaded skills, scheduled prompts and the actions you approved with don't ask again. Open or close it with the side panel toggle in the session view.

Skill chip: in the diagram the Excel skill builds the spreadsheet before the Email skill sends it. Watching the chips is the fastest way to see how Cowork decomposed the request.

Which skill to steer: when a step stalls or produces the wrong output, the chips tell you which skill was running at that point.
