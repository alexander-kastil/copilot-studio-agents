# Schedules and triggers

## Content

- A **schedule** repeats a prompt daily, weekly, monthly or at a set time, up to 25 of them
- The **Automations** page lists every run and lets you edit, pause, resume or delete a schedule
- **Activate and run now** starts the first run at once; Activate waits for the next scheduled time
- A **trigger** starts the task when an email, a Teams channel message or a Teams chat message arrives
- The **custom skill** decides how the task is done; the schedule or trigger decides when

## Speaker Notes

This slide turns a prompt you would run once into work that repeats. Cowork runs it on a schedule or when something happens, and delivers the result without you.

Schedule: write the prompt as usual, describing the full outcome, then set a recurrence of daily, weekly, monthly or a specific time. You can have up to 25 scheduled prompts.

Automations page: open it from the left navigation, where Runs shows each past or upcoming run and Manage schedules lets you edit, pause, resume or delete. Create defines a schedule directly, and the side panel Schedule section works during a session.

Activate and run now: when you activate a draft schedule, this choice runs it immediately so you can watch its approvals. Activate on its own makes the first run wait for the next scheduled time.

Trigger: describe the trigger and the job in chat, and Cowork proposes a Set up trigger? card that you arm with Set up. Teams triggers can be limited to messages that mention you, and the Automations page shows each task as Active, Draft or Paused.

Custom skill: the skill carries your format and sources, the schedule or trigger carries the cadence. Point a schedule at a custom skill and you get repeatable, house-style output with zero manual effort.
