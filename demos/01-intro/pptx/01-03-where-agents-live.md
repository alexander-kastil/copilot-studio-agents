# Where agents live in Microsoft 365

## Content

- **Copilot Chat**: everyday drafting, summarizing and Q&A, no build required
- **Copilot Cowork**: recurring knowledge-work automation with skills
- **Agent Builder and SharePoint agents**: site-grounded and prebuilt agents, no code
- **Copilot Studio**: custom agents with topics, tools and orchestration
- Prototype without code, then **rebuild in Copilot Studio** when the process needs it

## Speaker Notes

The same agent concept shows up in several places, each suited to a different builder and audience.

Copilot Chat: everyone uses it for drafting, summarizing and Q&A, with nothing to build.

Copilot Cowork: business users automate recurring knowledge work with skills, low-code.

Agent Builder and SharePoint agents: makers build site-grounded and prebuilt agents with no code.

Copilot Studio: low-code makers and pro-code developers build custom agents with topics, tools and orchestration.

Prototype, then rebuild: a common pattern is to prototype in a no-code surface and rebuild in Copilot Studio when the process needs custom tools, multi-agent orchestration or governance. Nobody has to choose one path forever.
