# Agent Builder

## Content

- **Describe** the job in plain language, or configure each field by hand or from a template, then test on **Try it**
- **Knowledge**: SharePoint, OneDrive, Teams chats, your email, public sites, uploaded files and Copilot connectors
- **Share** it with people, or submit it to the org catalog for the Agent Store
- **No actions**: copy the agent to Copilot Studio when it needs connectors or workflows

## Speaker Notes

Researcher, Analyst and SharePoint agents come ready-made. Agent Builder is the next step: your own declarative agent, built inside Microsoft 365 Copilot with no code. Copilot Studio builds the same kind of agent on its Copilot chat harness, one of the four harnesses compared in the previous topics.

Describe: select New agent and describe the job on the Describe tab, and Agent Builder fills in the name, description, instructions, knowledge sources and suggested prompts. Skip to configure opens the same fields for manual editing, templates give you a preconfigured start, and the Try it tab tests the agent before anyone else sees it.

Knowledge: an agent grounds on up to four public URLs, up to 100 SharePoint files, folders or sites plus one SharePoint list, OneDrive files, Teams chats and meetings, your Outlook email, uploaded files and the Copilot connectors your admin enabled. Which sources a builder can add depends on their license.

Share: share with specific people, or with the whole organization when your admin allows it, and submit to the org catalog so an admin can approve the agent into Built by your org in the Agent Store. SharePoint agents are moving into Agent Builder from mid-November 2026.

No actions: Agent Builder can't author actions that call external services. When the onboarding agent needs a connector, a workflow or a custom tool, copy it to Copilot Studio, where Module 3 picks up.
