# Spending governance

## Content

- **Monthly spending limit**: the tenant's total ceiling for the billing period
- **Per-user limit**: the most any one user can consume
- **Alert thresholds**: notifications at set percentages of the limit
- Set them **at activation**, with numbers from the Cowork Estimator

## Speaker Notes

Pay-as-you-go without limits is a surprise waiting to happen, so this slide covers the guardrails you set when you enable it.

Monthly spending limit: this is the tenant's total ceiling for the billing period.

Per-user limit: it caps the most any one user can consume. A single heavy user cannot drain the tenant's credits.

Alert thresholds: notifications fire at set percentages of the limit, so you hear about spend before you hit the ceiling.

At activation: set all three when you activate, not after the first large bill. The Cowork Estimator helps you pick realistic numbers before go-live.
