# Overview

## Content

- Start with the vocabulary: **copilot**, agent and assistant, and where agents live
- **Agentic AI**: the goal-driven model and the design patterns teams build with
- **How agents work**: instructions, knowledge, tools, retrieval and MCP
- Pick an **extensibility path**, then license and set up the environment
- Finish with **Copilot Chat** and the ready-to-use productivity agents

## Speaker Notes

This slide walks the path through the module's six topics once, following on from the three themes of the title slide.

Vocabulary: topic one fixes what a copilot, an agent and an assistant are, and places Copilot Chat, Copilot Studio, Cowork and SharePoint agents on one map.

Agentic AI: topic two explains the shift from answering a question to pursuing a goal, and the patterns (single agent, multi-agent, deterministic flow, autonomous, human-in-the-loop) you design with.

How agents work: topic three takes apart the three parts of every agent, instructions, knowledge and tools, plus the semantic index, RAG and the Model Context Protocol.

Build path and setup: topic four picks the extensibility path and envisions the scenario, and topic five sets up full or pay-as-you-go licensing and the one-time tools.

Productivity surface: topic six closes with Copilot Chat, Researcher, Analyst and SharePoint agents, the baseline before you build your own.
