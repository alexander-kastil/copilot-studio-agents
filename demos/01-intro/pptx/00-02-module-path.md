# Overview

## Content

- The vocabulary and **how agents work**: the loop, instructions, knowledge and tools
- **Where to build**, and how Copilot Credits pay for it
- **Copilot Chat** and the productivity agents that come ready to use
- Optional: **prepare the tenant** with the licenses and credits each module needs

## Speaker Notes

This slide walks the path through the module once, following on from the three themes of the title slide.

Concepts: topic one fixes what a copilot, an agent and an assistant are and places Copilot Chat, Cowork, Copilot Studio and SharePoint agents on one map. Topic two explains how an agent pursues a goal in a loop, the three parts it is built from and the patterns you design with.

Where to build: topic three places Agent Builder, Cowork, Copilot Studio and pro-code on one effort scale, then shows the three billing routes for Copilot Credits and the spending limits to set at activation.

Productivity surface: topic four covers Copilot Chat, Researcher, Analyst, SharePoint agents and Agent Builder, the baseline before you build your own agent.

Tenant setup: topic five is optional. Take it when you prepare a class tenant, or when a demo stops at its first message for lack of credits.
