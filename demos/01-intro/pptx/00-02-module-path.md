# Overview

## Content

- Start with the vocabulary: **copilot**, agent and assistant, and where agents live
- **How agents work**: the goal-driven loop, instructions, knowledge, tools, RAG, MCP and the patterns
- **Where to build**: the build paths and how Copilot Credits pay for them
- Finish with **Copilot Chat** and the ready-to-use productivity agents

## Speaker Notes

This slide walks the path through the module's four topics once, following on from the three themes of the title slide.

Vocabulary: topic one fixes what a copilot, an agent and an assistant are, and places Copilot Chat, Copilot Studio, Cowork and SharePoint agents on one map.

How agents work: topic two explains the shift from answering a question to pursuing a goal, takes apart the three parts of every agent (instructions, knowledge and tools) with the semantic index, RAG and the Model Context Protocol, and maps the patterns you design with.

Where to build: topic three places Agent Builder, Cowork, Copilot Studio and pro-code on one effort scale, and shows the three billing routes for Copilot Credits with the spending limits to set at activation.

Productivity surface: topic four closes with Copilot Chat, Researcher, Analyst and SharePoint agents, the baseline before you build your own.
