# Agent Builder

## Content

- **Describe** the agent in plain language; Agent Builder fills in its instructions, knowledge and starter prompts
- **Configure** each field by hand or start from a **template**, then test on **Try it**
- **Knowledge**: SharePoint, OneDrive, Teams chats, your email, public sites, uploaded files and Copilot connectors
- **Share** it with people, or submit it to the org catalog for the Agent Store
- **No actions**: copy the agent to Copilot Studio when it needs connectors or workflows

## Speaker Notes

Researcher, Analyst and SharePoint agents come ready-made. Agent Builder is the step after them: your own declarative agent, built inside Microsoft 365 Copilot with no code.

Describe: select New agent and tell Agent Builder what the agent should do. It writes the name, description, instructions, knowledge sources and suggested prompts for you.

Configure: Skip to configure opens the same fields for manual editing, and templates give you a preconfigured start. Test the agent on the Try it tab before anyone else sees it.

Knowledge: an agent grounds on up to four public URLs, SharePoint files, folders, sites and one list, OneDrive files, Teams chats and meetings, your Outlook email, uploaded files and the Copilot connectors your admin enabled. What a user can add depends on their license.

Share: share with specific people, or with the whole organization when the admin allows it. Submitting to the org catalog sends the agent to an admin, who can approve it into Built by your org in the Agent Store. SharePoint agents are moving into Agent Builder from mid-November 2026.

No actions: Agent Builder cannot call external services. When the agent needs a connector, a workflow or a custom tool, copy it to Copilot Studio, which is where Module 3 picks up.
