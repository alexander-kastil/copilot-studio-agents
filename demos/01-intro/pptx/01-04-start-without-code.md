# Start without code, grow into Copilot Studio

## Content

- **Copilot Chat**: everyday drafting and Q&A, nothing to build
- **Copilot Cowork**: recurring knowledge work with skills
- **Agent Builder and SharePoint agents**: makers, no code
- **Copilot Studio**: custom agents with topics, tools and orchestration

## Speaker Notes

The same agent concept shows up in several places in Microsoft 365, each suited to a different builder and audience.

Copilot Chat: everyday drafting, summarizing and questions and answers. Everyone uses it, and there is nothing to build.

Copilot Cowork: recurring knowledge-work automation with skills, set up by business users without code.

Agent Builder and SharePoint agents: site-grounded and prebuilt agents that makers create without code.

Copilot Studio: custom agents with topics, tools and orchestration, built by low-code makers and pro-code developers.

The diagram shows the common pattern: you do not choose one path forever. Prototype in a no-code surface, then rebuild in Copilot Studio when the process needs custom tools, multi-agent orchestration or governance.
