# Spending limits
### Guardrails set when you activate Copilot Credits
- **Monthly spending limit**: the tenant's total ceiling for the billing period
- **Per-user limit**: the most any one user can consume, at least 2,000 credits a month
- **Alert thresholds** below the ceiling notify you before it is reached
- Set them **at activation**, with numbers from the Copilot Credit Estimator

# Licenses and credit sources
### Few seats, and credits charged where the work runs
- **Per user**: a Microsoft 365 Copilot license, Copilot Studio access and a GitHub account
- Everything else is **Copilot Credits** or an Azure resource on one subscription
- Credits are charged **where the work runs**: agent environment, developer environment or tenant
- Each maker's **personal developer environment** needs the billing plan too

# Takeaways
### What to carry into the Cowork module
- Every agent is a copilot with a **narrower job and more autonomy**
- An agent works toward a **goal** in a loop, and a person approves consequential actions
- Fix a weak agent by naming its thin part: **instructions, knowledge or tools**
- Choose the **harness** before you create the agent: it fixes behavior, features and billing
- Take the **lowest-effort path** that meets the need, and set **Copilot Credit** limits before the first bill
