# Copilot Studio Basics

## Content

- Create a **Standard agent** and set its instructions, model and orchestration
- Ground it in **knowledge** and shape its conversations with topics, Power Fx and Adaptive Cards
- **Publish** it to Teams and Microsoft 365 Copilot

## Speaker Notes

This module is where makers get their footing with Copilot Studio, Microsoft's low-code platform for building agents. It works with Standard agents, the ones many clients run in production today.

Standard agent: you create one in an environment, give it an identity and instructions, pick its model and decide how it orchestrates its answers. In the New agent menu it is Agent with the Standard badge under Other ways to build.

Knowledge and conversations: knowledge grounds the answers with citations, and topics, entities, variables, Power Fx and Adaptive Cards shape the conversations you want to control.

Publish: the goal is a working, grounded agent in Teams by the end, built without writing code. Everything here carries over to GitHub Copilot agents, which reuse the same concepts under a consolidated Build surface.
