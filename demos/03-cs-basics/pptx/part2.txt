# Power Fx in a topic
### Three formulas turn the expense card into a claim ready to save
- Formulas run wherever a node takes a value: **Set variable value**, Condition, Question
- `Text(GUID())` gives every claim its own **claimID**
- `& "T00:00:00Z"` turns each card date into an **ISO timestamp**
- Name variables with their **scope prefix**, separate arguments with commas

# From card inputs to variables
### Input id, binding and type must agree
- Each input **id** becomes a typed output bound to a topic variable
- `Global.orderDemand` keeps all nine numbers for the order calculation

```
output:
  binding:
    qty.WienerSchnitzel: Topic.qtyWienerSchnitzel
    qty.PizzaNapoli: Topic.qtyPizzaNapoli
    qty.GreenCurry: Topic.qtyGreenCurry
outputType:
  properties:
    qty.WienerSchnitzel: Number
```

# Takeaways
### What the tools module builds on
- Write **instructions** that state the job, the limits and how a conversation ends
- Give every knowledge source and topic a **description** the orchestrator can choose by
- Trust an answer once its **citation** opens the source
- Keep fixed paths in **topics**, logic in **Power Fx** and multi-field input on **Adaptive Cards**
- Users chat with the **published** version, and only once you share it
