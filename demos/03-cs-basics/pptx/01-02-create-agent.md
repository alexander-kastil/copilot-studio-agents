# Creating a Standard agent

## Content

- Three starts: **describe** the agent, **Create blank agent**, or an agent template
- A blank agent needs only a **name**
- **Agent settings** show language, solution and schema name; the demo keeps the defaults
- The agent stays in the **environment** selected before you create it

## Speaker Notes

With the parts in mind, the demo creates its first agent. The screenshot is the Name your agent dialog from the live run of CS-Employee Onboarding Assistant.

Three starts: a description of up to 1,024 characters generates the name, description and instructions, Create blank agent asks only for a name, and a template such as IT Helpdesk gives a working agent to tailor. The demo starts blank, so the instructions added next are the only behavior the agent has.

Name: the CS- prefix marks the agent as part of the class environment. After Create the agent shows Setting up for about a minute, so reload the Overview page before you edit.

Agent settings: the optional section shows the language, the solution and the schema name. The demo keeps all three defaults.

Environment: the environment you select before you create the agent is the one it stays in. Pick a dedicated development environment for anything you plan to move to production later.
