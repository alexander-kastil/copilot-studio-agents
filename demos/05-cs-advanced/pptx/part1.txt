# Autonomous agents and triggers
### A trigger is a Power Automate flow that prompts the agent
- An **event trigger** fires when something happens in another system, not when a user types
- It sends the agent a **payload** with the event's data, and the instructions decide which tools run
- Behind every trigger sits a small **Power Automate flow** that sends the agent a prompt
- In the lab, a resume PDF in SharePoint becomes an employee record through the **HR MCP server**

# Deep reasoning and the reason keyword
### Only the step that carries the keyword runs on the reasoning model
- **Deep reasoning (preview)** is a switch in the agent's Settings and needs generative orchestration
- The keyword `reason` in an instruction step forces the reasoning model for **that step only**
- Learn's deep reasoning article names **Azure OpenAI o3** for the reasoning steps
- The **activity map** shows a deep reasoning node wherever the model ran

# Generative orchestration
### How the planner turns a request into a multi-step plan
- The planner reads a request and picks **topics, tools, knowledge and other agents** to answer it
- The **description** weighs most in that choice, then the name
- One plan can chain **several steps** and writes one reply from what they returned
- Event triggers, deep reasoning and other agents all need **generative orchestration**
